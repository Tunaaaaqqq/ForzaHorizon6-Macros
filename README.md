# AutoHotkey Macros

Private collection of AutoHotkey v2 game macros.

## Files

- `22B WheelSpin Loop.ahk` - wheelspin loop macro using randomized waits.
- `Forza Skill Point.ahk` - skill point loop macro using randomized waits.

## Usage

1. Install AutoHotkey v2.
2. Download or clone this repo.
3. Double-click the `.ahk` script you want to run.
4. Focus the game window.
5. Press `F6` to start or stop the macro.
6. Press `F7` to stop the macro.

## Notes

These scripts are intended for private single-player use. Check a game's rules before using macros online.
